## Project Title: CS122 Final Project

## Description: For our final project, we intend to use Steam's API. With this API we intend to pull information on Steam's extensive catalog of published games. We plan to then use this information to generate graphs that group based on genre or tags. Data that we are looking to analyze are the average costs and ratings of games. With the GUI we are planning to make, users would be able to select data they'd like to visualize and graphs would be locally generated.
